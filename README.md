# Piezocatalysis LCA Modeling Skill

[![Zenodo DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23813629.svg)](https://doi.org/10.5281/zenodo.23813629)

供科研 Agent 使用的生命周期评价（LCA）技能包，适用于压电催化、光催化和压电光催化研究。工作流覆盖实验数据审查、前景清单、背景数据映射、情景复算和科研交付。

An agent skill for life-cycle assessment of piezocatalytic, photocatalytic and piezo-photocatalytic systems. It supports evidence review, foreground inventory, background mapping, scenario recalculation and reproducible reporting.

## 快速开始 / Quick start

1. 在支持 Agent Skills 的环境中加载 `piezocatalysis-lca-modeling/`。Agent 从 [SKILL.md](piezocatalysis-lca-modeling/SKILL.md) 进入工作流。
2. 按[使用手册 / User manual](USER_MANUAL_BILINGUAL.md)准备实验数据、功能单位和研究边界。初次使用可运行[合成前景示例](piezocatalysis-lca-modeling/assets/examples/synthetic-foreground/README.md)。
3. 需要软件联调时，参阅 [openLCA 工作流](piezocatalysis-lca-modeling/references/openlca-workflow.md)或手册中的 [SimaPro 指南](USER_MANUAL_BILINGUAL.md#7-simapro-quick-start--simapro-快速开始)。
