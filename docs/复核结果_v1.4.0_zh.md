# 新版本综合复核记录

本次复核覆盖实验数据证据链、压电催化领域检查、ecoinvent 数据集映射审查和科研交付，以及它们之间的衔接。修复内容见[候选版本说明](RELEASE_v1.4.0_zh.md)。

在本机受控副本中，合成案例依次经过逐循环前景、证据与领域检查、清单及映射、openLCA IPC 计算、结果覆盖检查、图表和研究交付；另对原 ecoinvent 数据库的受控副本运行候选查询。基准和高功率情景各完成 32 个影响类别的计算。生成的交付与重新整理的交付各有 35 个文件通过摘要校验，方法说明、LCIA 表及两类图表的 SVG 和 PNG 共六个文件逐项一致。

案例中有代理数据、未连接的催化剂最终处置和待审核的映射，因此它验证的是流程，不支持比较真实方案的优劣。交付状态保留为需复核；重建交付不重新运行 openLCA。文件摘要用于发现变动，不是数字签名，也不能证明原始测量或方法选择正确。

带绘图依赖的环境中，开发工作树 257 项测试通过，Skill 格式检查和 Git 差异空白检查通过。将 v1.3.0 标签导出到独立目录后，139 项测试通过，作为回滚演练。完整的本机联调记录与受许可约束的数据库衍生数据保存在本机，不纳入公开发布材料。
