# v1.7.8 维护候选

本地候选延续 v1.7.7。openLCA 2.7.0 每次计算都扫描影响因子表，两套复算库各有 2,098,489 行。Derby 只按影响类别筛选时，返回给 Java 的行数缩到 1,436 和 4,679，但执行计划仍全表扫描。两轮完整复算确认这种做法没有稳定收益。[openLCA 影响因子构建源码](https://github.com/GreenDelta/olca-modules/blob/v2.7.0/olca-core/src/main/java/org/openlca/core/matrix/ImpactBuilder.java)

候选在通过组件哈希核验的 macOS 临时守护 JVM 中，每个计算工作线程复用同一隔离库、同一类别集合的原始因子行，最多保留一组、64 个类别和 16,384 行。每个情景仍由 openLCA 原有的逐行处理逻辑计算公式、单位换算、地域默认和不确定性。超过上限或遇到重复因子键时走原查询，保留矩阵赋值语义。

## 复算验证

同一台 Mac 分别运行 v1.7.7 与候选的 `scenario_suite.py rerun --workspace`，使用相同的合成和 BiOCl 归档。三轮交替版本顺序，端到端计入进程和临时服务启动、复算、校验、服务退出及结果写出。

| 案例 | v1.7.7 均值 | v1.7.8 候选均值 | 耗时减少 |
| --- | ---: | ---: | ---: |
| 合成逐循环 4 个情景 | 18.13 秒 | 15.49 秒 | 14.6% |
| BiOCl 4 个情景 | 17.31 秒 | 15.57 秒 | 10.1% |

合成三轮均更快，BiOCl 三轮有两轮更快。全部 200 项 LCIA 数值、类别与单位，1,416 条贡献、17,456 条总清单流及快照逐项一致。结果时间戳、临时结果 ID 和包含它们的两个摘要随运行生成，各归档均通过原有校验。

另用虚构库对比两版的因子行为。非地域化与地域化结果分别为 13 和 17，公式因子默认结果为 10，复用同一因子行并覆盖参数后结果为 18。重复因子案例两版均为 22，读取探针确认候选走原查询。边界检查已并入现有本机 openLCA 守护联调入口。
