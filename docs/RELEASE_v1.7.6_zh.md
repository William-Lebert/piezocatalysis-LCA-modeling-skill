# v1.7.6 维护版说明

openLCA 批量复算可能在 `--wait-seconds` 用完后继续等待状态请求。v1.7.5 还会接纳超过期限的就绪响应。v1.7.6 从取得结果 ID 时开始计时，用剩余预算约束状态请求的 socket 超时，拒绝迟到的状态响应。超时后仍尝试释放临时结果，并保留释放失败的错误信息。结果读取和释放各自使用常规连接超时。

计算入口要求等待时长为有限的正数。布尔值、非有限数值和非正数会在请求计算前报错。此检查也覆盖从 JSON 配置运行的多情景套件。

在同一台 macOS 上使用 openLCA 2.7.0 的隔离库逐一复算。200 项 LCIA、1,416 条贡献、17,456 条总清单流，以及产品系统、供应方、影响方法、类别和参数快照均逐项一致。

| 同一批案例 | v1.7.5 端到端 | v1.7.6 端到端 |
| --- | ---: | ---: |
| 合成逐循环 4 个情景 | 25.01 秒 | 23.43 秒 |
| BiOCl 4 个情景 | 21.29 秒 | 22.77 秒 |

每个版本各跑一轮，计入启动、复算、服务退出、比对和结果写出。设置 0.5 秒等待预算模拟迟到的状态响应时，v1.7.5 在 2.27 秒后仍返回成功，v1.7.6 在 0.58 秒后报超时并释放临时结果。

如需回退，可在独立目录安装 v1.7.5 的 Skill，保留研究输入和复算记录。[v1.7.5 仓库提交](https://github.com/William-Lebert/piezocatalysis-LCA-modeling-skill/commit/a1dbdc74f562c09be4b37bc295bafd718e5e6e7a)
