# v1.7.9 维护候选

把分散的复算计时和结果核对合并到 `tests/benchmark_scenario_suite.py`。入口沿用原有 `scenario_suite.py rerun`，记录每轮耗时、归档与运行组件哈希，并对照 LCIA、贡献、总清单流和快照。运行设置、各次复算输出与汇总报告保存在同一个目录。[复算基准操作说明](openlca-regression-benchmark.md)

以 v1.7.8 为基线，用同一批合成和 BiOCl 归档跑两轮。全部八个情景逐项对照了 200 项 LCIA、1,416 条贡献、17,456 条总清单流和快照。该对照验证了基准入口，计时用于记录两次运行的耗时分布。

新增一组 33 个供应过程的合成回归。Derby 日志确认优化路径先按 ID 查 32 次，再执行一次原全量查询。对照路径的 LCIA 都为 56.0，贡献、总清单流和快照逐项相等。正常的实际计算入口与守护 JAR 沿用 v1.7.8。

README 精简为用途、快速开始、文档入口及正式归档引用。论文引用与机器可读元数据统一指向正式归档 v1.7.0。维护版历史见 [CHANGELOG](../CHANGELOG.md)。
