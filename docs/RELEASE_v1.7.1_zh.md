# v1.7.1 维护版说明

这次把时间花在日常复算和交付上。openLCA 预检按 UUID 查询映射用到的过程和地域代码，并复用本轮已经读取的过程数据。计算前后各做一次核对。在本机四组 BiOCl 情景的对照中，复算耗时从 89.3 秒降到 80.3 秒，约节省 10%，计时从 IPC 服务就绪后开始。72 项影响结果均与 v1.7.0 记录一致。

LCIA 覆盖审查一次整理好各类别的表征因子和清单项。同一个流属性的参考单位在本次审查中查询一次。交付校验会对照包内复现规格点齐证据、结果表和图表。比如交付清单漏记已声明的结果文件，校验会指出缺少的条目。

已有情景记录可用原规格复算。每份记录仍会校验自己的完整摘要，复算对照继续核对映射、模型快照、单位和影响结果。BiOCl 案例的五水硝酸铋继续留待补齐背景数据。

可选的 Brightway 合成示例改用 Python 3.12，更新了依赖扫描发现的三个软件包。旧环境清单继续保留，方便追溯之前的计算。

复核还补上了几处异常处理。取消计算时会回收 openLCA 已分配的临时结果，重复的影响类别和缺少流标识的清单行会报错。复算核对记录的表征因子是否对应指定流，交付核对原始规格和复现规格，也会提前识别 Windows 和 macOS 上可能互相覆盖的证据文件名。
