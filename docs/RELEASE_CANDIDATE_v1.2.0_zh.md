状态：候选，尚未发布。正式仓库 `William-Lebert/piezocatalysis-LCA-modeling-skill`；本次检查时远端 main 为 `9e877b48a4b393d89773bc00d7ebc4eb82328fbd`，已发布 `v1.1.1` 标签为 `b63e095ecb24ac45f5ddbe09c4d6efc165389354`，远端未发现 `v1.2.0` 标签。发布时重新核对远端状态。

## 主要变化

1. 清单映射：从 openLCA 过程描述符查询候选，记录过程、参考流、属性和单位的可选 UUID，明确地域、来源与审核状态；旧映射格式仍可使用，候选不自动选定。
2. 实验前景：从带来源和证据类别的记录生成批次／单次清单，分别支持干催化剂产量与污染物表观去除量功能单位；支持缺失值、检测限／定量限、单位换算和明确的重复计量检查。
3. 参数重算：通过 openLCA 查询参数并逐情景重算，记录方法、数据库声明、参数、结果以及输入和代码哈希；匿名摘要供审阅。保留原贡献量近似工具并明确区分。
4. 本机启动：openLCA 2.7.0 图形界面生成应用包缓存后，自动启动会在临时程序副本排除已知缓存并重新执行完整签名校验；签名资源被修改仍拒绝启动。原应用和原数据库保持不变。
5. 修复零去除量时误终止生产报告，以及过程描述符地域为空时的查询异常。

## 验证结果与边界

- Python 标准测试：104 项通过；语法编译和 `git diff --check` 通过。
- 在实际 macOS 默认路径、包含 GUI 缓存的 openLCA 2.7.0 上，合成库真实引擎测试通过：旧版 3.2／6.4、参数基准 4.8 与单因素 8／8／4，重复结果一致；写入被拒绝，签名文件篡改被拒绝。项目自有 guard jar 可重复构建。
- 使用默认路径对 ecoinvent 3.9.1 cut-off 临时副本只读查询，获得 35 个流属性。第 2 批曾在单独数据库副本中验证 1 个合成前景连接中国低压电力聚合背景：GUI 与 IPC 的 32 个指标一致，GWP100 为 1.942690 kg CO2-Eq／虚构服务。原库文件路径、大小和修改时间摘要未变；该摘要不是内容哈希。
- 两组合成前景和参数情景均为虚构数据，不代表真实实验或科学结论。浓度变化不证明矿化；等性能复用是研究者需要确认的假设。数据库、方法选择和使用许可仍需结合具体研究核对。
- 自动启动目前针对项目验证过的 macOS openLCA 2.7.0 和 APFS；既有本机 IPC 服务不由该启动器配置，参数单位和数据库身份需使用者确认。
