# 待审版本说明与回滚方案

版本：**v1.1.0**，计划日期 2026-11-08。新版本的 Zenodo 版本 DOI 尚未取得；不得沿用 v1.0.0 的版本 DOI 指代本版本。

## 候选版本变更

- 加强数值、清单和模型结构验证，拒绝非有限数、部分畸形输入和缺失的必填来源。
- 新增可溯源的前景清单审查、单位换算、数据集映射和污染物去除功能单位缩放。未映射条目保留为空并提示，代理及待审核映射须人工审查；缩放依赖案例所列的恒定表现与平均分摊假设。
- 新增本机 openLCA 2.x JSON-RPC 只读客户端：读取描述信息、调用已有产品系统计算、读取结果并尝试释放临时计算资源。客户端的方法白名单不等于服务器本身只读；启用 IPC 前须核实服务器监听范围和访问控制。数据库身份、单位及其他元数据需要人工确认。
- 新增单因素敏感性与绝对结果报告，提供情景调整、排序、贡献核对和溯源。基准、情景与替代贡献的证据类别分开记录；替代值来源和证据由用户提供。该功能不进行 LCIA，也不能证明输入之间在科研上可比。
- 提供独立 Brightway 合成可行性实验和版本记录；未将 Brightway、lca_algebraic 或 premise 加入核心依赖，后两者尚未实机验证。

## 兼容性和迁移

- 模型规格中的前景项目需补全 `stage`、`direction`、`source` 等字段；旧输入应先通过结构校验，并人工检查科研完整性。清单映射表需补充 `mapping_id` 和 `rationale` 等模板规定的列。
- 敏感性输入中每个 `replace` 调整项新增必填 `replacement_evidence_class`，与既有 `replacement_source` 一起填写；不得简单假设它与情景的 `evidence_class` 相同。调整后的组成项新增基准来源、基准证据和情景证据字段；消费报告的程序应容忍新增字段。缩放项的 `evidence_class` 为 `calculated`，反映派生计算，并不证实情景假设。
- 示例均为合成数值，不可当作实际测量、ecoinvent 因子或已验证的压电催化研究结论。具体单位、边界、映射和方法仍需人工核查。

## 验证与已知限制

- 以发布审查时重新运行的测试结果为准，记录 Python 和操作系统、命令及结果；不要仅凭本草案认定通过。
- 已有本机 openLCA 2.7.0 隔离合成案例历史记录：2 kg 虚构排放 × 1.6 虚构因子得到 3.2；并非 ecoinvent 的真实产品系统验证。
- Brightway 独立合成案例与手算交叉核对过；该环境及冻结清单只对本次记录的机器和 Python 版本有证据，不含下载哈希。其他平台、真实数据、lca_algebraic 和 premise 未验证。
- 敏感性排序采用绝对数值升序及精确并列；对负值、避免负荷和不可简单以低值代表更优的指标，必须由研究者解释。该报告不覆盖统计不确定性、非线性建模和真实 LCIA 重算。
- 第三方项目及其许可信息见 README；数据库和方法包的具体使用及分发授权仍需分别确认。

## 回滚方案

- **发布前发现问题**：保持正式 main 不变，在开发分支修复或停止；已有用户数据和 openLCA 数据库不需恢复。
- **Git 发布后发现问题**：先记录当前 main、故障范围、已发布 tag/Release 和备份，并暂停后续发布。若使用合并提交，将针对该合并提交的反向变更准备为可审查 PR；若 squash 合并，则针对 squash 提交反向变更；若快进或多个普通提交，按实际提交依赖关系逆序准备反向变更。多人协作时使用新的 revert 提交，不强推或重写公开历史。先在隔离副本测试回滚和原有功能，再按发布流程获得确认并合并。已有 tag/Release 的处理单独审查，避免误导使用者。
- **使用方恢复**：可在独立目录检出已核对的发布前提交 `8958a82`，或按需要使用历史标签 `v1.0.0`（其提交为 `31bc5833f617dd6f72d3a14d4f7a967615f05997`；它早于上述发布前 main，二者并非同一版本快照）。安装旧版技能前先备份用户现有技能目录及数据；不覆盖或删除任何数据库。旧版不支持新版输入字段的全部行为，旧输出应保留且标记生成版本。
- 回滚操作应在具体故障发生后按以上步骤单独执行；不更改数据库。
