# v1.8.0 版本说明

这一版汇集了上次正式归档以来的改动，重点是让 openLCA 多情景复算更省时，让计算结果和科研交付更容易复核。

在经核验的 macOS openLCA 2.7.0 环境中，守护启动器使用隔离数据库副本和索引查询，并在有限范围内复用描述符、结果引用和表征因子原始行。遇到超出上限或有歧义的数据，仍走 openLCA 原查询。每轮计算重新生成结果，并保留计算前后的快照。[复算基准与回归入口](openlca-regression-benchmark.md)

计算等待超时后，如果 openLCA 仍在后台排程，客户端会在独立的清理窗口内等候，再请求释放临时结果。清理等待最多 30 秒，超限仍尝试释放并报告确认不足。同一虚构合成库用于核对 LCIA、贡献、总清单流和快照，以及恢复计算后旧结果 ID 的状态。[手动 IPC 验收](../platforms/windows/README.md#手动-ipc-真机验收)

用同一批合成和 BiOCl 案例对照 v1.7.9，八个情景的 200 项 LCIA、1,416 条贡献、17,456 条总清单流和七类快照字段一致。在 Windows 11 ARM64 虚拟机和 macOS 上手动启动 openLCA 2.7.0 IPC，用同一份 33 个供应过程的合成库核对了结果和快照。恢复计算后，原超时结果 ID 仍查不到。

科研交付会核对复算规格、证据和产物清单，并在完整组装后提交输出目录。已有场景记录继续按记录中的原始摘要校验。升级时保留原始数据、参考数据库副本和已有交付，首次复算写到新目录。[迁移说明](migration-notes.md)
