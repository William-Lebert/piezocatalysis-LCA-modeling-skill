# v1.6.0 版本说明与回滚方案

这次更新把压电催化研究中从实验记录到结果交付的几段工作接了起来。处理 H₂O₂ 产物时，Agent 可以保留产物基准和实验来源；处理循环实验时，可以把每次使用的样品、测量记录和服务判定对应起来，让清单中的数字更容易追溯。

情景比较增加了与 openLCA 实际产品系统、交换、背景提供过程和参数的绑定。计算前后还会复核映射，并确认所用参考过程、参考交换和单位。科研交付可以一起整理计算结果、情景比较、敏感性资料、图表和方法说明，也新增了真实实验资料准备清单。

我们用本机 openLCA 和 ecoinvent 背景跑通了两类合成案例：H₂O₂ 产品案例，以及包含基准、高功率和低表现情景的逐循环案例。逐循环案例中的催化剂末端处置仍未连接，结果用于检查流程和记录，不用于宣称真实技术优劣。加和敏感性案例使用单独的虚构输入，并非 openLCA 重算结果。

## 升级提示

新情景采集采用 `piezolca.bound-scenario/2`。旧版记录可继续留存；如需进行绑定比较或重新生成交付，请重新采集情景，再重建比较和图表。其他既有清单与证据材料应按照各自的迁移说明检查。

## 发布与回退

Zenodo 元数据按确认的角色列出 Pu, Xiaoyu（作者、项目负责人）和 Gu, Jing（贡献者、相关人员）。

如需回退，可从 GitHub 的 v1.5.0 标签或对应归档恢复代码，并保留新旧研究数据及输出；不要用旧代码覆盖原始实验数据。回退后使用与旧代码匹配的记录格式，重新执行项目测试和所需的 openLCA 检查。受 ecoinvent 许可约束的数据库和衍生结果应留在有使用权限的环境中。
