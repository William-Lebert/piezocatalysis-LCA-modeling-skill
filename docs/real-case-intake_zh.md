# 真实实验案例：数据准备清单

请先将原始实验记录保存在受控位置，按授权范围提供副本或标准化表格；无需把个人联系信息、许可证或数据库文件提交到公开仓库。可用 `piezocatalysis-lca-modeling/assets/templates/real_case_intake.template.json` 记录材料位置和缺口；留空表示未知，不用零补齐。模板用于整理，不是合规或质量认证。

1. **研究目标与服务**：说明比较对象、污染物或 H₂O₂ 产品、功能单位、所需出水或产品质量、系统边界、时间和地域。水相浓度降低只支持条件明确的表观去除，不自动说明矿化或毒性降低。
2. **原始证据**：提供有使用权限的仪器记录、实验记录与采样表，记录本地路径、文件摘要、工作表/单元格或文献页码；列出批次、样品 ID、进出水角色、取样时间、复测、校准与检测限。标准化 CSV 是中间材料，需逐项对照原件。
3. **逐循环与催化剂**：每循环记录进出水体积及浓度、负载/补加/回收催化剂、清洗再生、损失及末端去向；区分真实观察次数和假设或外推寿命。未测、未检出、低于定量限和真实零值分开记。
4. **能源与物料**：记录超声及辅助设备是实测墙插功率、设备读数还是额定估算，运行时间及量程；记录光照、氧化剂、pH 调节、洗涤、制备、产率和废物处理，注明数据来源及证据类别。
5. **H₂O₂ 产品（如适用）**：明确净积累、回收产品及使用位置，测量方法、外加量修正、原位消耗和催化剂分摊；不要自动把不同产品基准或污染物去除服务当成等价。
6. **背景与软件**：记录获得授权的数据库版本、系统模型、地域、LCIA 方法和 openLCA 版本；逐项审核候选数据集、参考产品、单位、输入/输出方向、供应商和代理偏差。背景数据库及受限衍生数据按许可保存。
7. **独立核对**：提供一个可手算的质量或能耗锚点和一个预先约定容差的计算对照；由领域研究者和独立 LCA 审阅者分别核对来源、功能单位、边界、映射、覆盖和结论。缺失、相关性和不确定性应明确列出，不因文件摘要通过而视为已获批准。

进一步步骤和验收边界见 [真实案例验证方案](real-case-validation-protocol.md)。
