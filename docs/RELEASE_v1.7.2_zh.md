# v1.7.2 维护版说明

本版集中维护科研交付和 openLCA 情景绑定。交付先在同一文件系统的临时目录中复制并核对文件，报告写完后再整体移到目标目录。组装时即使原文件被修改，检查与交付仍使用同一份副本。写入失败后可在原目标路径重试。交付核验统一按包内规则检查角色、文件名和摘要，证据 CSV 需要对应的规格与报告，交付包内的文件应为普通文件。

情景绑定先按前景过程和交换编号整理记录。带编号的绑定直接定位交换，旧绑定仍按流和其他条件匹配唯一交换。前景过程中出现重复交换编号时，检查会报错。原有提供者、单位、金额和计算前后快照检查继续执行。

本机的合成压力测试含 149 条前景活动、20,152 条技术交换记录。Python 前景匹配的中位耗时从 362 毫秒降至 2.1 毫秒。实测合成和 BiOCl 模型共复算 8 个情景，200 项影响结果在原复算容差内与存档一致。测试使用本机 openLCA 2.7.0 和隔离库，前景匹配计时单独记录。

## 使用与回退

已有按标准工具生成的交付仍可用原复现规格重组。如果旧包内含符号链接、被手工改名的交付文件或缺少对应报告的证据附件，请从原规格重新组装。需要回退时，用 v1.7.1 的已知提交安装到单独目录，并保留已有输入与交付。[v1.7.1 仓库基线](https://github.com/William-Lebert/piezocatalysis-LCA-modeling-skill/commit/2c3a0cf89ce609072792a76fca9c3013de8f35b0)
