# v1.3.0 版本说明与回滚方案

状态：v1.3.0 版本说明和回滚记录；是否已发布及归档以 GitHub Release 和 Zenodo 为准。最近正式版本为 v1.2.0，版本 DOI 为 `10.5281/zenodo.24203326`，正式标签指向提交 `2688559c7e5d0e8b3e7e2cee3693346b084caf11`；其后 main 的 DOI 文档回填提交是 `51b582670df99569f0c9c88d9e8ffeb0ed9e730b`。这两个快照不同，发布前重新核对远端。

## 候选变化

- **映射与 LCIA 核对**：逐项检查选定过程的参考交换、单位、方向、指定供应方链接和所选基本流的表征因子；缺失属性、数值或公式因子不会误判为已核实。
- **逐循环前景**：记录每轮装载、回收、补加、进出水质量、清洗与再生；检查质量连续性、干湿基、检测限和未知值，并输出已按功能单位缩放的清单。原恒定性能入口保留。
- **情景和数据质量**：检查声明的边界、功能单位、数据库、方法等可比性；整理数据质量、分布与变量依赖声明。有限联合状态抽样只用于合成验证，不是 openLCA 原生蒙特卡洛或真实研究概率推断。
- **只读对接**：受控本机服务新增 `data/get` 单实体读取，以支持映射核验。运行期间其他本机进程也可能读取单个数据库实体；写入／删除接口仍受限制。与现有签名和版本约束相同。

## 验证与使用边界

- 139 项标准测试通过；受控 openLCA 合成库、参数重算与防护测试通过。恒定／变化两组逐循环清单分别经过校验、合成供应方与 LCIA 映射、真实引擎计算和参数重算；合成总值为 35.2／16.704，超声倍率翻倍分别增加 1.6／0.96 个任意合成指标单位。表征因子仅为测试系数，不代表研究结论。
- 独立 ecoinvent 副本中的参数重算本次再次核对，4 组、32 类结果与此前一致；此前还验证过多阶段背景与 GUI／IPC。部分前驱体和废水是联调代理，废催化剂未连接。逐循环清洗／最终处置尚未完整接入该 ecoinvent 模型。GUI 和 IPC 使用同一个 openLCA 引擎。
- 功能单位清单已缩放，不能再次当作每批或每次数据交旧缩放器；无法计算时缺失值仍为空。浓度下降不证明矿化，催化剂未解释损失不自动指定处置。
- 未取得真实实验重复、分布和联合测量，暂不输出真实项目概率区间；原生 openLCA Monte Carlo 未由该版本客户端启用。数据库身份、映射和 LCIA 适用性仍需研究者审核。
- 商业 ecoinvent 数据库、真实研究数据及本机派生完整结果不纳入仓库或候选包；分享摘要前仍需检查内容与许可。

## 发布前检查

1. 审核最终代码、版本号、测试和归档清单；核对当前远端 main、标签及 Zenodo 状态，确认没有覆盖用户数据。
2. 确认版本后更新 README、CHANGELOG、CITATION.cff 的版本及实际日期，不提前填写尚未生成的版本 DOI；保留已有版本 DOI 和历史标签。
3. 用户授权发布后，按仓库规则提交、推送、创建标签与 Release；核实 Zenodo 自动归档和新 DOI，再以独立后续提交更新引用信息。

## 回滚

- 发布前：保留当前已发布 main 和研究数据库，停止或修正候选即可。
- 发布后：先记录实际发布提交和使用影响；在独立分支对相应提交执行 `git revert`，运行相关测试后以新提交恢复，不强推、不移动已公开标签。GitHub Release／Zenodo 记录的处理单独核对。
- 使用方可在独立目录检出 `v1.2.0` 标签 `2688559`；如需含 DOI 回填的发布前 main 则选择 `51b5826`。覆盖安装前备份当前技能和自定义配置，保留原有 openLCA 数据库、测试副本及实验数据。
- 复验老版本的合成与受控启动流程；逐循环、细化映射和不确定性准备文件在 v1.2.0 中不可用，须保留原始输入和结果作为独立研究记录。
