# v1.4.0 版本说明与回滚方案

版本：**v1.4.0**，2026-11-16。

这次更新围绕科研 Agent 的实际工作展开：从整理压电催化实验记录，到检查生命周期清单、寻找背景数据，再到整理计算结果和图表，尽量让每一步都能回到原始依据。

Agent 现在可以把标准化实验表格中的数值、单位和样品基准，与逐循环前景和每功能单位清单逐项对应。压电催化领域检查也更具体了：它会关注超声功率的计量方式、辅助设备和光照、氧化剂与 pH 调节、催化剂回收及处置，并提醒研究者区分水相表观去除与矿化。过氧化氢的净积累和回收产品也可以作为独立功能来建模。

在 openLCA 中查找 ecoinvent 数据集时，候选记录会保留地域、参考产品、单位、参考交换方向以及选用或拒绝理由。代理数据的适用依据和可能偏差也有位置记录。候选即使被选中，仍会以待审核状态交接给后续流程。

已有的清单、证据、映射、计算记录和图表可以整理成一份本地研究交付，附上方法草稿、文件摘要和待解决的问题。图表支持逐循环表现、阶段贡献等用途；情景与工程假设也可以单独记录。交付中的方法文字是根据已有记录生成的草稿，适合研究者继续核对和修改。

本轮复核还修正了几处衔接问题：检测限信息不完整时不会生成看似确定的区间；领域声明会与前景中的服务、污染物和边界交叉核对；已有映射编号会在交接时保留，共用或冲突的编号会提示人工处理。交付校验也会识别缺少必要文件记录的清单。情景检查和图表不再把自动检查结果当作方案排名的许可。

## 验证与使用说明

合成案例已经贯通实验数据、逐循环清单、映射审查、真实 openLCA 计算、图表和研究交付。测试使用本机 ecoinvent 3.9.1 cutoff 的受控副本，部分输入采用代理，最终催化剂处置仍未连接，因此结果只用于验证工作流。具体测试数量和记录以本次[综合复核报告](复核结果_v1.4.0_zh.md)为准。

使用真实数据时，研究者仍需要确认实验记录、数据集的地域和技术适用性、代理选择以及结果覆盖。当前证据工具可以核对标准化 CSV 并记录原始 Excel 或文献的位置，但不会自动核实这些原件的单元格或页面。交付中的重建配置用于重新整理已保存的材料，不会重新运行 openLCA。

# 回滚方案

上一个发布版本为 v1.3.0，其标签指向提交 `30e10fce56124ee4d680c10e4f85b9f0b0511122`；v1.4.0 发布前的 main 另有 DOI 文档回填提交 `01381945287ea9f6954fdbcd2fd06a833b10b0a2`。

- **发布前发现问题**：保留当前开发副本和测试记录，在候选上修复或暂停；已发布版本及数据库不需要改动。
- **使用方需要切回旧版**：先备份当前 Skill、自定义配置和研究输入输出，再将 v1.3.0 检出到独立的新目录，核对标签提交后切换。新版新增的证据链、候选审查和交付格式应作为独立记录保留，不要假定旧版可以直接处理。
- **仓库发布后需要撤回代码**：记录实际发布提交，在新分支使用适当的 `git revert`，复测后通过新提交恢复；不强推或移动已公开标签。GitHub Release 和 Zenodo 归档的后续处理另行核对。
- **研究数据**：不删除或替换原始实验文件、ecoinvent 数据库及独立测试副本；继续保存模型、功能单位、映射和结果的版本记录。
