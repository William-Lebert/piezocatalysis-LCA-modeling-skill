# 合成情景与工程放大

这些文件均为虚构输入，不是实测或设计建议。示例比较循环寿命、超声功率与处理时间、清洗换水、氧化剂、电网和设备容量；参数的 `basis` 区分实验测量、工程假设和合成测试，并用 `source`、`unit`、可选 `measured_range` 记录来源与测量范围。范围之外标记为外推，未提供范围则显示缺口。范围是声明，不自动推断分布、相关性、置信区间或适用性。

```sh
python3 piezocatalysis-lca-modeling/scripts/engineering_scenarios.py \
  piezocatalysis-lca-modeling/assets/examples/synthetic-engineering/spec.json \
  --output-dir /tmp/piezolca-engineering-report
```

Agent 可按任务调用上述脚本，导出 JSON 与 Markdown。输出目录必须不存在。`baseline_input` 和每个情景的 `input` 是独立的逐循环输入；程序先对每份输入单独重新计算每功能单位清单，再逐项比较。不同功能单位、边界、流标识、方向或单位不会计算相应差值；新增或移除活动不会视为零。所有输入差异也完整保存在 JSON，需人工审查实验服务和边界是否等效。

参数的 `input_pointer` 使用 JSON Pointer 指向单个数量对象（核对数值和单位），或指向 `/cycles`（以 `cycles` 为单位核对数量）；没有绑定指针的参数只作为设计声明，不改变清单。新增循环、氧化剂等必须写入新的前景文件。设备容量不自动转换成功率、循环数或污染物去除率，必须分别提供与量程匹配的设计和实验数据。

`background_electricity` 是用户声明的数据库、数据集标识、地域、参考单位与来源；变更时提示重新映射和计算，不沿用原有电网结果。可选 `comparison` 指向 `cycle_scenario_compare.py` 产生的真实计算比较报告，程序核对基准／情景输入 SHA-256 和可比性声明；实际模型交换、供应方及数据库身份还需独立回读，哈希不是真实性证明。绑定新电网的模型应单独重算并审核；本版对改变电网的比较不接收既有影响报告。未提供真实结果的情景只显示清单，报告不允许自动排名。

真实实验应记录重复、测量不确定性和参数关联；数据不足时不拟合分布。模型分位数和实验置信区间是不同概念。本例不执行蒙特卡洛、工程尺度性能预测或优化。涉及商业数据库及其衍生结果时，分享前核对许可。
