# Piezocatalysis LCA QA Checklist

- [ ] Goal and decision context are explicit.
- [ ] Functional unit and reference flow are consistent across systems.
- [ ] PZC, PC, and PPC power boundaries are explicit.
- [ ] Illumination inclusion/exclusion is justified.
- [ ] Every foreground value has an evidence class and source.
- [ ] Batch yield is measured or clearly labeled otherwise.
- [ ] Washing, separation, drying, and recovery are route-specific.
- [ ] Provider mappings and conversion factors are reviewed.
- [ ] Absolute LCIA results are archived before normalization.
- [ ] Contribution totals reconcile with total results.
- [ ] At least one manual scaling check matches the software.
- [ ] Sensitivity cases cover dominant uncertainties.
- [ ] Model identifiers and software versions are recorded.
- [ ] Licensed databases and private data are excluded from public files.
